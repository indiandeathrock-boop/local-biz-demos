## Entry 001: ひとり広報アカデミー（共同ピーアール監修）クロージングウェビナー台本

- **出典**: 合同会社クラップコミュニケーションズ運営「ひとり広報Academy」。共同ピーアール株式会社（東証スタンダード上場、2436）と株式会社VAZが監修。「1人候補全国300人誕生記念特別オンラインセミナー」のクロージング部分（文字起こし）。
- **分析日**: 2026-07-17
- **主催/運営の実態**: 表面上は「共同PR全面バックアップ」を前面に出すが、実際の主催・ローンチ運用はスクール運営業者（クラップ社）。共同PRの立場は監修＋インターン受け皿の提供であり、自社名義でのローンチはしていない。上場企業（売上85億円規模、AI・ビッグデータ事業が40%増収の好調企業）にとって、このアカデミーは事業の柱ではなく、低コストで実働人材と将来の外注網を確保するオプションと見られる。

### 9フェーズの実装
| # | フェーズ | この事例での実装 |
| --- | --- | --- |
| 1 | 再点火 | 「地域に眠っている魅力を見つけ出して世の中に届けて…自分も地方に挑戦してみたい」と読み手の内心を代弁 |
| 2 | ピボット宣言 | 「ですがここからはかなり現実的なお話をさせていただきます」で夢話から転調し、以降の話に「正直さ」の枠をかける |
| 3 | 壁の提示 | 壁1（地域にいないと無理・物理）／壁2（いても仕事は取れない・信頼関係）／壁3（実務スキルがないと無理・能力）。各壁に固有名詞エピソード（宮崎のライチ、共同PR伊藤氏の島根での実地活動、香川ホテル開業案件で岡山出身生徒がテレビ3番組露出を獲得） |
| 4 | 絶望の底 | 「経験を積めないから未経験のまま」という悪循環を言語化。「1人でゼロからやるのは現実的にかなり厳しい」と、読み手を責めず構造の問題として描写 |
| 5 | 救済の予告 | 「アカデミーを開行して2年以上、全国300人以上の受講生と向き合う中でずっと考えてきた」という使命の物語。「解決しない限り地方は衰退していく」という社会的緊急性 |
| 6 | 1対1の回収 | OJT制度→壁3の解決、47都道府県OJT制度→壁1・壁2の解決。証言（未経験で不安だった生徒の声、「うまくいかないことも多い」という欠点開示込み）＋数字入り事例（テレビ3番組露出）。「3つの壁を全て綺麗に取り払うことができました」と明示宣言 |
| 7 | 物量の提示 | 1年間ロードマップ（基礎3ヶ月→中間テスト→応用3ヶ月→卒業試験→フォロー半年）＋「12の環境とサポート」を、不安の代弁（「恥ずかしい」「1人でやりきれるか不安」）から始める形式で列挙 |
| 8 | 権威の担保 | 「共同PRさんが本気だから」「共同PRも現に人材不足を感じており期待を寄せている」と利害込みで説明。共同PR役員2名（伊藤氏・木村氏）の生声メッセージで締める |
| 9 | クロージング機構 | ①審査制（誰でも入れない）→②理由（「提携先企業に迷惑がかかるから」「人数的にサポートしきれないから」）→③募集期間3日間→④「悩んでる段階で申し込んでもらっても大丈夫」とハードル引き下げ→⑤公式LINE一本に導線を単一化→⑥早い者順を明示 |

### 個別技法（writing-rules.md該当箇所）
- **逆算された問題設計**: 3つの壁＝商品3機能（OJT・47都道府県ネットワーク・カリキュラム）の鏡像 → writing-rules §2「9フェーズ型・3原則①」
- **reason-why限定**: 「提携先に迷惑がかかるから審査する」「人数的に厳しいから絞る」 → writing-rules §4「reason-why限定」
- **構造への責任転嫁**: 「悪循環のループ」＝あなたのせいではない → writing-rules §4「構造への責任転嫁」
- **元・読み手の証言**: 不安だった未経験者の声、欠点開示込み → writing-rules §4「元・読み手の証言」
- **権威の利害開示**: 「共同PRも人材不足だから本気」 → writing-rules §4「権威の利害開示」
- **貢献への変換**: 「あなたの力が必要」「地元に恩返し」で自己投資の罪悪感を無害化 → writing-rules §0.5「動かす目的」の応用
- **絞ると見せて絞らない**: 審査制で期待を煽った直後にハードルを下げる二段構え。技術としては高等だが要注意（下記判定参照）

### LBSへの適合性判定
- **そのまま使う**:
  - 壁の逆算設計（ブロック3）。GBP無料診断LPなら「自分でやると続かない・何が正解か分からない・業者に頼むと人質にされる」の3壁を、RKのLBS提供機能から逆算して立てられる。
  - 1対1の回収と明示宣言（ブロック6）。壁を立てたら必ず全部消す。消せない壁は立てない。
  - reason-why限定（ブロック9②）。「ひとりで運営しているため、無料診断は月○件まで」は事実であり、演出なしでそのまま最強の限定になる。
  - 構造への責任転嫁（ブロック4）。「集客できないのは店主の怠慢ではなく、情報格差の問題」はRKのLBSの思想そのもの。
  - 権威の利害開示（ブロック8）。「なぜ安いのか・なぜドメインを客名義にするのか」を自分の利害込みで説明する誠実さは、この事例の「共同PRも人材不足だから」と同じ機能を果たす。
- **改変して使う**:
  - 締切（ブロック9③）。3日間の煽り締切は、加藤さん経由の温かい紹介導線とは非整合。「今月の診断枠」のような事実ベースの締切に置き換える。
  - 貢献への変換。地域貢献はLBSの本物のナラティブだが、購買正当化の道具として過剰演出すると本事例と同じ「気持ち悪さ」を生む。事実の範囲で淡々と語る。
- **使わない**:
  - 絞ると見せて絞らない二段構え（審査で期待させて実質全通し）。透明性を売りにするLBSの思想と構造的に矛盾する。絞るなら本当に絞る（診断枠の実数限定のみ）。
  - 使命の物語の誇張。実績数字が積み上がるまで、ブロック5は控えめに実装する。ウソのV字は書かない（writing-rules §4 ストーリーテリング鉄則）。

### 学び（一般化できる示唆）
- 「なぜプレスリリース＋有料講座という正攻法でなくローンチ形式なのか」という問いへの答えは、実際に売っている主体（クラップ社）と、名前を貸している権威（共同PR）が別法人だから、というのが一番筋が通る説明。上場企業が自社名義でこの種のクロージング技術を使うことは考えにくい（ブランド・IRリスク）。RKが単独名義で活動する場合、この非対称は生まれない＝むしろ正直な設計をそのまま通せる強みになる。
- 中高年をターゲットにする力学は、AI研修セミナーと共通。①可処分資産と補助金の両方を持つ層である ②「実務経験がないと評価されない」という構造的弱点を本人たちが最も痛感している層である ③「地元への恩返し」という感情フックが最も強く効く層である、の3点。
