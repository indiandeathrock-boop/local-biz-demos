# レベル分類定義 (L0〜L5)

導入記録の「レベル分類」欄はこの定義を使う。ツール・仕組みが属する習熟レベルを記す。

- L0 利用者: Claude.ai / Claude Code / API の違いが分かり、基本的なチャット利用ができる
- L1 設計者: 明確なプロンプト設計(役割・出力構造・例示・反復改善)ができる
- L2 構造化者: 仕事をloop/skill/agent/goal/hook/MCPの6分類に振り分けられ、CLAUDE.mdを設計できる
- L3 運用者: サブエージェント・スキル・フック・/loopを実際に運用し、安全設計(承認フロー)を組み込める
- L4 接続者: MCP・APIの仕組みを理解し、外部ツール導入を4軸(権限/ブラスト半径/保守リスク/代替可否)で評価できる
- L5 建築家: advisor型/orchestrator型などのマルチエージェント設計ができ、他人に教えられる
