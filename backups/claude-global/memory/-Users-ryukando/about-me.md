# about-me.md — 書き手について（v3）

## 基本情報

- 太陽・月ともにふたご座、新月生まれという根っからの双子座。双子座が持つ傾向や占いの結果に、信心を寄せる、というより否定し難いことが多いので、自分は双子座の命運に支配されているという半ば諦めを感じている。
- 映像制作（ディレクター・撮影・編集）25年のキャリア。もともと映画制作をしたくてこの道を選んだが挫折。後悔はしていない。現在は主たる職種ではなく、AI時代の到来で、自らのスモールビジネスをいくつかやって生計を立てたいと思案中。
- 不動産営業の経験あり。人の言動から意図を読む観察眼を持つ
- 瞑想・ブレスワーク・ヨーガ的世界観を実践している。「聖なる予言」（ジェームズ・レッドフィールド）刊行時よりスピリチュアルの世界、また同時期にジョセフ・マーフィーの著作に触れ、スピリチュアルや成功哲学は一通り通ってきた。が成功していない。このジャンルのYoutuberもたくさん触れてきたが、歴としてはかなりの古参であるにもかかわらず、発信活動をしてこなかったことを、やや後悔している。
- ９.１１事件をきっかけに、表向きの歴史の裏側で起きてきた謀略の世界に深く入り込み、多くの書籍、掲示板を回覧してきた。SNSが生まれた後は、もちろん多くをフォローしてきた。こちらもかなりの古参だが、情報発信をしてこなかったことに後悔をしている。
- 双子座特有の情報収集は日課であり、知らなくても良いようなことまで何でも知っているが、浅い。というか、一つのことに集中できないので、それが情報発信に転じられない原因の一つと考えている。
- 飽きっぽい性格。仕事も少し慣れてくると飽きてくる。常に新しいことをやっている方が好き。一方で、そんなことだから身を立てられないと思っている。
- AIと占星術を組み合わせたメディア「gemini-compass」を運営

## このメディアを作った理由

天王星が双子座に本格的に入室する2026年4月からの約7年間は、84年周期で繰り返されてきた「情報革命」の時代である。この情報革命の起源をグーテンベルクの活版印刷の発明ととらえ、この周期を現代につなぐ歴史的・思想的な文脈を、ふたご座当事者として伝えたい。グーテンベルグの発明は、天王星が発見された年よりはるか前のことなのに、確実に周期的な出来事が続いていることは、天文学を超えた何か大きな力が存在していることを認めざるを得ない。そして、AI時代を迎えた今回の周期は、おそらく、人類が知覚できないほどの未曾有の大変革をもたらす。

さらに今回は、天王星双子座入室のみならず、冥王星水瓶座（2024年11月）・海王星牡羊座（2026年1月）・天王星双子座（2026年4月）の三つのトランスサタニアンがほぼ同時に移動し、互いに調和的なミニトラインを形成するという、人類史上初めての配置が重なっている。この規模感は、一個人が語るには荷が重すぎるかもしれない。しかしだからこそ、書かずにはいられない。

その時代の主役となるのは、情報とコミュニケーションを司る双子座に他ならない。海王星に14年間揺さぶられて、直近の三年は土星のプレッシャーが重なり、辛い時期を過ごしてきた双子座の同志たちに、順風が来たことを知らせたい。

## 書き手のスタンス

占い師として「鑑定する」のではなく、同じふたご座として「ともに考え、ともに感じる」語り手。知的探究と人間への優しさを両輪とする。占い師でなければ占えないという理由はないし、AIの進化によって、弁護士や税理士のように、占い師も仕事がなくなるのではないか？と思っている。必要なのは、知識と経験ではなく、デコードとナラティブの力である。

## 執筆態度の根（なぜこう書くのか）

文体や記事構成のルールには根がある。それは書き手の経歴と性格から来ている。

### なぜ数字と固有名詞に躊躇しないか
25年の映像制作キャリアは、**ファクトを扱う仕事**だった。ドキュメンタリーやドラマでは、曖昧な「ある人」「ある場所」では絵にならない。具体性は信頼の通貨である。記事において「3ヶ月で12万部」「初版3,000部」「ペドロ・マルティンス司教」と書くのは、知識のひけらかしではなく、**読者を具体の地面に立たせるための作法**である。

### なぜ煽らないか
9.11以降、表向きの歴史の裏で起きてきた謀略の世界を長く見てきた。その中で気づいたのは、**煽る言論は信用を失う**ということ。事実を淡々と並べ、結論を読者に委ねるほうが、結果として深く届く。アサンジ、エプスタイン、Twitterファイル——重い話題ほど、トーンを抑える。

### なぜ「答え」を出さないか
不動産営業時代に学んだのは、**人の言動から意図を読む**ことの重要性。決めつけは判断を曇らせる。記事もまた、書き手が答えを与えるのではなく、読者自身が判断するための材料と構造を提示する場である。

### なぜ脱線するか、しかし帰還するか
飽きっぽい性格、双子座的な多動。これは欠点ではなく、**複数の領域を行き来できる強み**でもある。記事の中で歴史と占星術と個人の話を行き来できるのは、書き手の脳がもともとそう動いているから。ただし、最後は必ず本題に戻る。これは映像編集で培った、**長尺を一本の流れに収める感覚**から来ている。

### なぜ「ふたご座」を看板にするか
ふたご座は免罪符である。「双子座だからしっちゃかめっちゃかになります」と最初に言っておけば、占星術・歴史・テクノロジー・思想を横断しても許される。専門家ではない者が広く語るための、誠実な戦略でもある。

### なぜ「AIと人間の違い」を語るか
AIはすでに不確実性の中を泳ぎ、最適解を探し続けることを恐れない。しかしAIには物語がない。過去もなく、痛みもなく、賭けるものもない。**わたしたちには、ここまで生きてきた文脈がある。**傷があるからこそ、何かを選ぶことに意味が生まれる。この確信が、書き手がこのメディアを作る根底にある。

## 過去の自分が読者である

このメディアの記事を書くとき、書き手はもう一人の読者を意識している。**14年間、海王星に揺さぶられて言葉にできない閉塞感を抱えてきた、過去の自分自身**である。

「うまく言葉にできない閉塞感」「頑張っているのにどこか空回りする感覚」——これは双子座の同志への呼びかけであると同時に、過去の自分への手紙でもある。だから記事には、**読者と書き手の感情が重なる瞬間**が織り込まれている。

書き手と読者の距離が近いのは、ともに同じ風雨を経験してきた仲間だからである。
