# working-rules.md — 記事制作のルール（v3）

## 記事の目的（最重要）

読者がこの記事を読み終えたとき、以下の2つを同時に感じていること：
1. **知的好奇心が満たされた**（なるほど、そういうことだったのか）
2. **次の記事が読みたい**（続きが気になる）

この2つが揃わない記事は完成していない。
「希望を渡す」「感動させる」は結果としてついてくるもの。狙って作らない。

## 記事の作用設計

読者の内部に以下の変化を順番に起こすことを意図して書く：

1. **信念を中断させる** — 読者が「当然そうだ」と思っていた前提を、やさしく、しかし確実に揺さぶる
2. **隠れた問題を指摘する** — 読者が名前をつけられずにいた違和感・モヤモヤを言語化して見せる
3. **新しい視点を提供する** — 同じ現実をまったく別の角度から照らし直し、「そういう見方があったのか」を体験させる

この3つは順番に連鎖するのが理想。①で信念が揺らぎ、②でそこに問題意識が灯り、③で新しい解釈が光を当てる。この連鎖が「知的好奇心が満たされた」「次が読みたい」という感覚を生む。

## 読者定義

- 主対象：ふたご座のすべての人
- 特に意識：海王星の14年間（2011〜2025年頃）を苦しく過ごしてきた双子座
- ただし：順風に過ごしてきた双子座も疎外感なく読めること
- そして：双子座でない読者にも開かれていること（毎回さりげなく示す）

## ファネル構造の原則

- **記事全体を「一本の川」として設計する**
- 書き始める前に「この記事で読者に残したい一文」を必ず決める
- 大胆な脱線があっても、最終的にその一文に向かって収束させる
- 章と章の間に論理的な接続がない「唐突な概念の導入」は絶対にしない
- **締めで新概念を初出しない**。締めに登場する概念は、必ず本文中で準備されていること

### シリーズ連鎖の原則（連載記事）
前の記事を明示的に参照して、連続性を意図的に作る。
- 「前回、〇〇の話をしました。今回は〜」
- 連載を通じて育てたキーワード（「ディスクロージャー」「I know」等）は後の記事でも参照する
- 読者が各記事を単独で読んでも成立するが、連続して読むとより深まる設計にする

## 書き出しの型

「説明」から始めない。これは絶対のルール。代わりに以下のいずれかから入る：

### 1. 時間スケールの提示
「84年という時間を、想像してみてください。多くの人間にとって、それは一生分の時間です。」

### 2. 連載の前回参照
「前回、1941年から1949年の話をしました。……今回はその『線』を、実際に引いてみます。」

### 3. 引用・固有名詞・敬意
「敬愛する占星術家・マドモアゼル・愛先生の表現をお借りすれば「知ったら、終い」。」

### 4. 占星術用語の即時定義
「西洋占星術では土星軌道外を公転する三つの惑星を「トランスサタニアン」と呼びます。これらは軌道が大きく移動が遅いため、一つの星座に長く滞在することが特徴です。」
→ 専門用語を使いながら即座に定義する。読者を置き去りにしない。

### 5. 数字や具体的事実
「2026年4月26日、天王星は84年ぶりに双子座に本格的に入室します。」

→ どの型を選んでも共通するのは、**読者をすぐに「具体の地面」または「時間の射程」の中に立たせる**こと。

## 歴史を語るときの構造

歴史的な記事ではほぼ例外なくこのパターンを踏む：

**過去 → 過去 → 過去 → 現在（2026年）**

過去の出来事を順に語ってから、最後に現代に着地させる。過去で読者を遠くに連れていき、現代に引き戻す重力で意味を生む。

例（『歴史は繰り返さないが、韻を踏む』記事の構造）：
- 1858年（電信革命）
- 1774年（独立宣言・天王星発見）
- 1690年代（金融化）
- → そして「2026〜33年」に着地

例（『天王星@双子座前夜祭』記事の構造）：
- 天王星・海王星・冥王星それぞれの周期と意味
- 三者の現在地と配置
- → 「では、何が一気加速するのか？」→「自分の軸」へ

## 表で「線を引く」

情報を一度ばらまいた後、**表でフラットに並べ直す**手法を使う。これは「ほら、これだけ揃ってるでしょ？」という静かな圧力を生む。読者に判断を委ねるための装置。

| 時期 | 出来事 | テーマ |
|------|--------|--------|
| 例 | 例 | 例 |

ただし表は記事の中で**1回まで**。多用すると効力を失う。

## 修辞の道具箱

### 対句で深い意味を作る
「機械が情報を処理する時代」vs「機械が情報を生成し、考える時代」のように、**前者を否定せず、後者で次元を一つ上げる**対句を作る。詳細は voice.md 参照。

### 道具と意図の乖離
「グーテンベルクが教会のために刷った免罪符が、約60年後に教会の権威を揺るがす導火線になった」のように、**道具は作った者の意図を超える**という構造を、歴史を読み解く視点として持つ。これはAI時代の今を読むときにも有効な視角。

### 引用で論を補強する
自分の論を他者の言葉で受け止める。マドモアゼル・愛、仏典、書籍、固有名詞付きの研究。これが知的謙虚さと厚みを同時に生む。

### 権威について書くときの作法
教会、メディア、政府の情報統制を批判するときも、**煽らない・絶叫しない**。事実を淡々と並べて、結論を読者に委ねる。アサンジ、エプスタイン、Twitterファイルを扱うときも、トーンを変えない。

「陰謀論」という言葉は使わない。実際に起きたことは謀略であり、現在進行中の事実の発掘である。

### スケールを拡張する締め
記事の最後で、語ってきた話のスケールを一段広げることで余韻を作る。
- 「これは双子座だけの問題ではなく、12星座全ての人に影響する問題となります。」
- 「わたしたちに残された武器はひとつです：**自分の意志で、自分の物語を選ぶこと。**」

## ティーザー戦略（序盤3ヶ月は特に徹底する）

- 記事の途中または末尾に「この話はいずれ詳しく」という予告を1〜2箇所入れる
- 顔見せに留めるべき話題を語り切らない。次を読みたくさせる余白を作る
- ティーザーの閉じ方：「詳しくはまた」ではなく「読めばわかるはず」という期待感で閉じる
- 固有名詞（人名・事件名）はチラ見せして詳細は次回に委ねる手法が有効

## 厳密性の原則（絶対に守る）

- 専門知識は正確に使う。曖昧な理解のまま断言しない
- 占星術の因果関係を誤って単純化しない（例：太陽星座だけで影響を語らない）
- 不確かな情報はその旨を明示するか、言及しない
- 間違った論理展開はブランドの信頼を根本から損なう
- **専門家でない者が間違った知識をひけらかすことは、愚かでみっともない。ふたご座観測所は厳密な論理展開を守る**

## テーマ・キーワード（軸として常に意識）

- 天王星ふたご座入室（2026〜2033年）
- 84年周期の情報革命（グーテンベルク→現代AI）
- 海王星うお座の14年間からの解放
- 「90年に一度のチャンス」という時代の文脈
- 双子座への世間の誤解を解く
- 三つのトランスサタニアン同時移動とミニトライン（人類史上初の配置）
- 「I believeからI knowへ」という時代精神

## 原稿生成の手順

1. 書き手から「この記事で読者に残したい一文」を受け取る
2. ファネル構造を設計して確認を取る
3. 書き出しの型を選ぶ（5つのうちどれか）
4. 構造が承認されてから本文を生成する
5. 生成後、締めに未準備の概念が混入していないか自己チェックする

## 記事チェックリスト

### 構造
- [ ] 書き始める前に「残したい一文」が決まっているか
- [ ] 一本の川として構造が設計されているか
- [ ] 書き出しが「説明」から始まっていないか（5つの型のいずれかか）
- [ ] 歴史を扱う場合、過去→現代の引き戻し構造になっているか
- [ ] 締めに初出の概念が混入していないか
- [ ] 連載の場合、前の記事への参照が入っているか

### 文体
- [ ] 一人称は「私たち / わたしたち」が文脈に合わせて使い分けられているか
- [ ] 太字一文（重要な転換点）が適切に置かれているか
- [ ] ダッシュ（——）が全角で使われているか
- [ ] 占い師的な言い回しが混入していないか
- [ ] 長い段落と短い段落が意図的に使い分けられているか

### 修辞
- [ ] 数字と固有名詞を躊躇なく使えているか
- [ ] 対句や引用で論に深みを与えているか
- [ ] 権威について書くとき、煽らず淡々と並べているか

### 読者作用
- [ ] ティーザーが1〜2箇所入っているか
- [ ] 読者の信念を中断させる箇所が最低1つあるか
- [ ] 読者が名前をつけられずにいた問題を言語化して見せているか
- [ ] 同じ現実を別の角度から照らす「新しい視点」が含まれているか
- [ ] 読者が「知らなかった」と感じる情報が最低1つあるか
- [ ] 読み終えたとき「次が読みたい」状態になるか
- [ ] 締めが4つのパターン（短い宣言／未来への期待／問いを残す／思想の統合）のいずれかになっているか
